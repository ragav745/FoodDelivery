# 🍔 Food Delivery Website

A modern and responsive Food Delivery web application built using **HTML, CSS, and JavaScript**. This project provides an intuitive user interface where users can browse food items, explore categories, add products to the cart, and enjoy a seamless online food ordering experience.

---

## 🚀 Features

- 🏠 Responsive Home Page
- 🍕 Food Categories
- 🔍 Search Functionality
- 🛒 Add to Cart
- 💰 Price Display
- 📱 Mobile Responsive Design
- 🎨 Attractive User Interface
- ⚡ Fast and Smooth Navigation

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
